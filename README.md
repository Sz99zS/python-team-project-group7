# Командний Python-проєкт: Аналіз продажів (Варіант 7)

## Опис проєкту
Консольний додаток для імпорту та аналітики таблиць продажів. Програма зчитує дані про товари та прибуток з текстового файлу, розраховує загальний фінансовий результат та визначає найбільш прибутковий товар сезону.

## Розподіл ролей у команді
* **Студент А (Team Lead / Integrator):** Stepan Zubko — відповідає за архітектуру проєкту, створення структури, модуль імпорту даних (`io_utils.py`) та фінальну інтеграцію в `main.py`.
* **Студент В (Developer / Tester):** Sofiia Sibutina — відповідає за розробку математично-аналітичного блоку (`analysis.py`), валідацію та тестування працездатності коду.
